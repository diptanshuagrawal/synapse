## Usage — `/cron-status`

If invoked with `help`, `-h`, or `--help` as the argument: print this Usage block verbatim and STOP — do not run the script.

**What it does:** Runs the ingest cron status script and prints the health dashboard — per-source lanes, last success, pending counts.

**Usage:** `/cron-status` — takes no arguments.

```bash
$HOME/context/work-context/bin/cron-status.sh
```
